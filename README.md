# WLandStudio

> Web oficial de **Wasteland Studio** y su serie flagship **Wasteland: Japan Apocalypse** (Minecraft narrativo post-apocalíptico). Whitelist por invitación + formulario público.

## Cómo correr

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/
npm run typecheck
```
